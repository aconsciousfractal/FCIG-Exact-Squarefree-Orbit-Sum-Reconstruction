\section{Certificates and independent replay}
\label{sec:atlas}

The certified atlas $\CertifiedAtlas$ is a collection of finite mathematical objects with an
explicit dependency graph.  It is not a substitute for the statements and
proof explanations in Sections~\ref{sec:n4}--\ref{sec:conditional}.  Its role
is to expose every enumerated carrier, coordinate, collision, witness, and
lower-bound transition to a checker.

\subsection{Independent implementation paths}

The five-vertex computation uses separate producer and checker code trees.  The
producer generated groups by direct permutation enumeration and evaluated
support orbits by its own incidence path.  The checker generated groups by
closure from generators, reconstructed support orbits independently, and
evaluated coordinates by contained-support accumulation.  Neither imported
the other's module or trusted a producer-generated separator mask.  The two
complete canonical payloads are byte-identical.

For the lower proofs, the checker reconstructs all $534$ core pattern pairs,
all coordinate IDs, and every separator mask before reading DAG transitions.
It then checks reachability, acyclicity, every branch child, and every packing
or coverage leaf.  Thus neither a stored separator mask nor an optimizer
status is accepted as proof authority.

The assurance label is deliberately limited: the implementations are independent in
implementation and data path.  This is not a claim of blind human replication
or independent model-family authorship.

\subsection{Hashes and semantic checks}

A hash authenticates that the checked byte string is the same byte string
later inspected.  It does not show that the string encodes the intended group,
coordinate evaluation, or proof rule.  Those assertions are verified by
reconstruction.  The atlas therefore stores transport evidence (the manifest
and hashes) together with semantic evidence (explicit patterns, supports,
integer values, and local branch rules).  No hash-only oracle is accepted for
a mathematical result.
